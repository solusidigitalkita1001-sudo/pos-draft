# Coding Standards

## Naming Convention

Controllers

ProductController
TransactionController

Actions

CreateProductAction
UpdateProductAction
DeleteProductAction

Requests

StoreProductRequest
UpdateProductRequest

Policies

ProductPolicy

## General Rules

Use:

- Typed Properties
- Typed Parameters
- Return Types

Always use:

- Strict Validation
- Transactions when modifying stock

Avoid:

- Raw SQL
- Business Logic in Controller
- Massive Controllers
