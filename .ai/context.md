# POS Internal Context

## Project Information

Name: POS Internal

Description:
Internal Point Of Sales system for managing products, inventory, transactions, vouchers, refunds, returns, users, roles, permissions and team management.

## Tech Stack

Backend:
- Laravel 13
- PHP 8.3+

Frontend:
- React
- TypeScript
- Inertia.js
- Vite

Authentication:
- Laravel Fortify

Authorization:
- Spatie Laravel Permission

Database:
- MySQL

Deployment:
- Docker

Testing:
- Pest

## Development Philosophy

- Laravel First
- Convention over Configuration
- Simplicity over Complexity
- Action Pattern
- Team Scoped Data
