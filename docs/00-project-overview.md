# POS Internal

## Overview

POS Internal adalah sistem Point Of Sales berbasis web yang digunakan untuk mengelola operasional penjualan dan inventory.

## Goals

- Mengelola produk
- Mengelola stok
- Mengelola transaksi
- Mengelola voucher
- Mengelola promosi
- Mengelola user dan team

## Main Features

- Multi Team
- Role & Permission
- Product Management
- Inventory Management
- POS Transaction
- Refund
- Return
- Voucher
- Reporting
